院長 Dashboard Pro v7.1.1

変更点
- 月曜日を休診日としてAI・経営スコア・曜日分析から除外
- 土曜日を午後診療として専用目標で評価
- 病院設定タブを追加
- 通常診療日／土曜日の売上目標と基準来院数を変更可能
- 臨時休診日を登録可能
- 曜日分析を診療時間補正後の目標達成率で比較

更新前にデータタブから完全バックアップを保存してください。

月替わり自動切り替え
- 起動時に保存中の年月と現在年月を比較し、異なる場合だけ「○月のデータへ切り替えますか？」と確認します。
- 「はい」で当月の売上・支出・診療KPI・AIコメント・月次メモを初期状態にし、年間データ、過去月、病院・天気設定、バックアップ対象データを保持します。口座残高は前月値を引き継ぎます。
- 「あとで」はデータを変更せず、次回起動時に再確認します。一度切り替えた月には再表示しません。
- 過去月は月間・年間・財務・レポートで閲覧できますが、日次実績、月目標、財務の保存対象は現在月だけです。
